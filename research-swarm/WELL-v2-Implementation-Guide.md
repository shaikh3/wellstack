### 🚨 Senior Living-Specific Considerations

| Concern | Why It Matters for Seniors | Action Required |
|---------|---------------------------|-----------------|
| **PM2.5** | Elderly have reduced lung function; particles enter bloodstream faster | Install HEPA filtration in all common areas |
| **CO₂** | Cognitive decline at lower thresholds in seniors; dementia risk | Target 800ppm max, not 1,000ppm |
| **Formaldehyde** | Seniors spend 90%+ time indoors; off-gassing from furniture | Choose GREENGUARD Gold certified furniture |
| **VOCs** | Medications + cleaning products = higher exposure | Use only EPA Safer Choice products |

## ✅ Section 2: Step-by-Step Compliance Checklist

### Phase 1: Pre-Registration (Weeks 1-2)

#### ☐ Step 1: Eligibility & Scope Assessment
- [ ] Confirm facility qualifies as "senior housing" (supervised care + support services)
- [ ] Calculate gross floor area (GSF) for pricing
- [ ] Determine: Full Certification vs. WELL Core (if leased spaces exist)
- [ ] Identify target certification level: Bronze, Silver, Gold, or Platinum

#### ☐ Step 2: Team Assembly
- [ ] Designate WELL Project Administrator (can be property manager)
- [ ] Identify WELL AP (Accredited Professional) - *Required for complex projects*
- [ ] Engage MEP engineer for air quality systems review
- [ ] Assign facilities coordinator for ongoing monitoring

#### ☐ Step 3: Initial Assessment
- [ ] Conduct baseline IAQ testing (hire certified lab)
- [ ] Document current HVAC specifications
- [ ] Photograph all regularly occupied spaces
- [ ] Create inventory of cleaning products (for A03 - Construction Pollution Management)

---

### Phase 2: Registration & Planning (Weeks 3-6)

#### ☐ Step 4: IWBI Registration
- [ ] Create account at wellcertified.com
- [ ] Pay enrollment fee: **$2,250** (after 25% senior living discount from $3,000)
- [ ] Submit preliminary project information
- [ ] Upload floor plans and occupancy data

#### ☐ Step 5: Feature Selection Strategy
- [ ] Select mandatory Preconditions (40 points minimum required)
- [ ] Choose Optimizations to reach target certification level:
  - Bronze: 40-49 points
  - Silver: 50-59 points  
  - Gold: 60-79 points
  - Platinum: 80+ points

#### ☐ Step 6: Budget Finalization
- [ ] Program fee: **$0.12/sq ft** (after 25% discount from $0.16/sq ft)
  - Minimum: **$6,000** (after discount from $8,000)
  - Maximum: **$73,500** (after discount from $98,000)
- [ ] Request performance testing quote (varies by location/scope)
- [ ] Capital improvement budget for upgrades
- [ ] Ongoing monitoring equipment budget

---

### Phase 3: Implementation (Months 2-6)

#### ☐ Step 7: Air Quality Infrastructure
- [ ] Install continuous monitoring sensors (see Section 3 calculator)
- [ ] Upgrade HVAC filters to MERV 13 minimum (MERV 16 recommended)
- [ ] Verify outdoor air intake meets ASHRAE 62.1-2016
- [ ] Install demand-controlled ventilation (DCV) for CO₂ management
- [ ] Seal all ductwork leaks (test with duct blaster)

#### ☐ Step 8: Policy & Operations
- [ ] Create smoke-free building policy (A02)
- [ ] Establish green cleaning program (A03)
- [ ] Document construction pollution management procedures
- [ ] Write IAQ incident response protocol
- [ ] Train all staff on WELL requirements

#### ☐ Step 9: Documentation Preparation
- [ ] Upload policy documents to WELL Digital Platform
- [ ] Compile equipment specifications (filters, sensors, HVAC)
- [ ] Create operations schedules (filter changes, calibration)
- [ ] Prepare commissioning reports
- [ ] Draft letters of assurance from contractors

---

### Phase 4: Performance Verification (Months 6-9)

#### ☐ Step 10: Pre-Verification Preparation
- [ ] Conduct 30-day continuous monitoring data review
- [ ] Verify all sensors are within calibration period
- [ ] Remediate any threshold exceedances
- [ ] Confirm all documentation uploaded to platform
- [ ] Schedule Performance Testing Organization (PTO)

#### ☐ Step 11: On-Site Verification
- [ ] Accompany PTO during walkthrough
- [ ] Provide access to all mechanical rooms
- [ ] Demonstrate sensor network functionality
- [ ] Answer technical questions about systems
- [ ] Review preliminary findings with PTO

#### ☐ Step 12: Final Review & Certification
- [ ] Address any PTO comments or deficiencies
- [ ] Submit final documentation
- [ ] Pay remaining program fees
- [ ] Receive certification decision (typically 20-25 business days)
- [ ] Display WELL certificate and marketing materials

---

### Phase 5: Ongoing Compliance (Years 1-3)

#### ☐ Step 13: Annual Monitoring
- [ ] Review continuous monitoring data quarterly
- [ ] Replace/calibrate sensors per manufacturer schedule
- [ ] Change HVAC filters on schedule
- [ ] Conduct occupant satisfaction surveys (M02)
- [ ] Update policies as needed

#### ☐ Step 14: Recertification Prep (Year 3)
- [ ] Begin recertification application 6 months before expiration
- [ ] Conduct new baseline testing
- [ ] Document any building changes
- [ ] Prepare updated operations manual
- [ ] Pay recertification fees

## 🧮 Section 3: Sensor Placement Calculator

### Formula-Based Deployment Strategy

#### Base Calculation

```
MINIMUM SENSORS = MAX of:
  • 1 sensor per 3,500 sq ft of regularly occupied space
  • 1 sensor per HVAC zone
  • 1 sensor per floor
  • 1 sensor per major space type (dining, resident rooms, common areas, therapy)
```

#### Senior Living-Specific Adjustments

| Factor | Adjustment | Rationale |
|--------|-----------|-----------|
| Memory care unit | +1 sensor per 2,500 sq ft | Higher sensitivity required |
| Resident rooms with mechanical ventilation | +1 sensor per 10 rooms | Individual air control |
| Shared bathrooms | +1 sensor per 2 shared baths | Humidity/odor concerns |
| Therapy/rehab areas | +1 sensor per 1,500 sq ft | Higher activity = more CO₂ |
| Dining hall | +1 sensor per 1,000 sq ft | Peak occupancy concentration |

### Sample Calculator: 50,000 sq ft Assisted Living Facility

```
BASE CALCULATION:
  Total regularly occupied space: 45,000 sq ft
  45,000 ÷ 3,500 = 12.8 → 13 sensors (base)

HVAC ZONES:
  Floors 1-2: 3 zones each = 6 zones
  Memory care wing: 2 zones
  Total HVAC zones: 8 → 8 sensors minimum

SPACE TYPE BREAKDOWN:
  Resident rooms: 60 rooms → 6 sensors (1 per 10)
  Dining areas: 3 spaces → 3 sensors
  Common/lounge: 4 spaces → 4 sensors
  Therapy/gym: 2 spaces → 2 sensors
  Admin/offices: 3 sensors
  Total by type: 18 sensors

SENIOR LIVING ADJUSTMENTS:
  Memory care: 8,000 sq ft ÷ 2,500 = 3.2 → +1 additional
  Shared bathrooms: 12 shared baths ÷ 2 = +6 sensors
  
FINAL CALCULATION:
  MAX(13, 8, 18) = 18
  + Memory care adjustment: 18 + 1 = 19
  + Bathroom sensors: 19 + 6 = 25

RECOMMENDED SENSOR COUNT: 25-28 units
```

### Placement Requirements (WELL Performance Verification Guidebook)

| Parameter | Requirement | Pro Tip |
|-----------|-------------|---------|
| **Height** | 1.1 - 1.7 m (3.6 - 5.6 ft) | Use wall mounts at seated eye level for senior comfort |
| **Distance from doors/windows** | ≥ 1 m (3.3 ft) | Measure from frame edge, not glass |
| **Distance from HVAC vents** | ≥ 1 m (3.3 ft) | Never in direct airflow |
| **Distance from printers/copiers** | ≥ 3 m (10 ft) | Place upwind of equipment |
| **Distance from humidifiers** | ≥ 1 m (3.3 ft) | Cross-contamination risk |
| **Ceiling mount** | Allowed with justification | Must be within breathing zone height range |

## 🔧 Section 5: Common Violations & Fixes

### Quick Troubleshooting Guide

#### Category A: Threshold Exceedances

| Violation | Common Causes | Immediate Fix | Long-Term Solution |
|-----------|--------------|---------------|-------------------|
| **PM2.5 >15 μg/m³** | Outdoor pollution infiltration, cooking, smoking | Activate portable HEPA purifiers | Upgrade to MERV 16 filters, improve envelope sealing |
| **CO₂ >1,000 ppm** | Undersized ventilation, overcrowding | Open windows, reduce occupancy temporarily | Install DCV, increase outdoor air supply |
| **Formaldehyde >27 μg/m³** | New furniture, flooring, cleaning products | Increase ventilation, remove sources | Specify GREENGUARD Gold materials, 2-week pre-occupancy flush-out |
| **TVOC >500 μg/m³** | Cleaning products, personal care, off-gassing | Switch to low-VOC products | Implement green cleaning program, material screening |
| **Ozone >100 μg/m³** | Photocopiers, electronic air cleaners, outdoor smog | Turn off ozone-generating equipment | Replace electronic air cleaners with media filters |

#### Category B: Documentation Failures

| Violation | Why It Happens | Prevention |
|-----------|---------------|------------|
| Missing calibration records | Vendor didn't provide certificates | Require calibration docs in all service contracts |
| Incomplete monitoring data | Sensor downtime not noticed | Set up automated alerts for offline sensors |
| Policy gaps | Staff turnover, outdated procedures | Quarterly policy reviews, annual training |
| Wrong product specifications | Purchaser unaware of requirements | Create approved products list, require pre-approval |

#### Category C: Senior Living-Specific Issues

| Violation | Root Cause | Resolution |
|-----------|-----------|------------|
| **Oxygen concentrator emissions** | Medical equipment in resident rooms | Dedicated exhaust for oxygen concentrator areas |
| **Incontinence product odors** | High ammonia/VOCs in memory care | Enhanced localized exhaust, activated carbon filtration |
| **Medication storage vapors** | Volatile medications in nursing stations | Sealed storage with exhaust, refrigerator for temp-sensitive |
| **Hair salon chemicals** | On-site salon services | Dedicated ventilation system, source capture at stations |
| **Hospice/palliative care odors** | Medical equipment, medications | Negative pressure rooms, HEPA + carbon filtration |

# WellStack Platform

Smart apartment platform combining operational device management with wellness intelligence.

## Features

### P1: Base Smart Home
- Portfolio/property/unit hierarchy
- Device management (locks, thermostats, sensors)
- Access control and alerts

### P2: Wellness Intelligence  
- IEQ monitoring with WELL compliance
- Wellness Score (0-100)
- Fall detection
- Sleep environment tracking

## Tech Stack

Next.js 14, TypeScript, Tailwind, Zustand, Recharts, Framer Motion

## Deployment

https://workspace-code-manager.vercel.app

## Local Development

```bash
npm install
npm run dev
```

## Why Built

To position as "SmartRent + Wellness" for senior living and wellness communities.
